# The first game (v1)

The repo also holds the first economy built for this entry, still live: https://saltline-lac.vercel.app/play/
(without `?game=v2`) on [`saltline.testnet`](https://testnet.nearblocks.io/address/saltline.testnet). It is a
salvage market: three broker NPCs with wallets, price tooltips with each broker's reason, **investing in a broker
that went broke**, a shared town story, and a fast-forward run by the contract itself (`simulate`, the Dockside's
"The week" tab).

It was rebuilt as v2 because its economy sat beside the shooter and not inside it: nothing a player owned could be
lost, so nothing had value. [`docs/GAME.md`](GAME.md) → "Why the first economy failed" says what was learned. Its
design is in [`docs/ECONOMY.md`](ECONOMY.md) and [`docs/CAMPAIGN.md`](CAMPAIGN.md), and its contract in `contract/`.

Its brokers are the only part of the project on a schedule: `.github/workflows/brokers.yml` runs one round every 15
minutes, each broker signing its own move with its own key.
